# Naming

**Chosen name: Aptil** — domain **aptil.ai**. Evokes *apt / aptitude* (being the right,
capable fit for the role). Short, abstract, brandable. Used across the codebase
(`PROJECT_NAME`, package names, UI); renaming later is a find-and-replace of `Aptil`/`aptil`
plus the domain.

2. Social handles (@aptil / aptilhq).

The `.ai` domain is set. No clear conflicting company surfaced in search, but a formal
trademark check is still worth doing before spending on brand assets.
